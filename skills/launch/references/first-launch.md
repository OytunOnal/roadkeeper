# The first launch

Once, before anything reaches real users.

- **Address:**
  - [ ] the domain bought, bound and on HTTPS;
  - [ ] the announced link is the one that will not change;
  - [ ] the build base-path-independent, with a test, so the host's default address keeps working.
- **Identity:**
  - [ ] a favicon;
  - [ ] the wordmark from the tokens, fitting at 390px;
  - [ ] a social card (OG image and meta);
  - [ ] a logo beyond the wordmark, decided either way.
- **Discoverability:**
  - [ ] `sitemap.xml` and `robots.txt`;
  - [ ] the site registered in Google Search Console and Bing Webmaster Tools, with the sitemap submitted, before the announcement;
  - [ ] registering is a `waiting-on-you` issue with the URLs and the verification record ready to paste.
- **The way back in:**
  - [ ] the tracker link on the product;
  - [ ] the triage labels in place.
- **Legal:**
  - [ ] the licence ADR and the source terms;
  - [ ] the whole git history scanned for secrets before a repo goes public;
  - [ ] what is collected, stated.
- **Accounts:**
  - [ ] two-factor on the registrar, the host and the code host;
  - [ ] a second person who can act on them, or "single admin" accepted.
- **Backup and restore:**
  - [ ] tried once where the product holds data it cannot regenerate.
- **A preview per branch:**
  - [ ] an address where a branch renders before it is merged, for what only the real host shows.
