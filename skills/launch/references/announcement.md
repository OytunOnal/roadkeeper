# Announcement

For a release that is announced:

- [ ] The announcement is the README told once: the same claims in the same words on every channel, and no promise the product does not keep
- [ ] The announced link reaches the product's one action with no signup, email or install in the way
- [ ] The maker can be in the thread for its first hours; the first comment is written before posting
- [ ] A `waiting-on-you` issue names the first 48 hours: what to watch, where, and the threshold that pulls the announcement. It closes when the window ends, with one line of what happened
- [ ] The window is a freeze: the live product changes only for a pull or a blocker
